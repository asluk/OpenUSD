# usdGeospatial (codeless schema)

Declarative OpenUSD schema for geospatial Coordinate Reference Systems, **codeless**
(no C++ build). File layout and core names are aligned with the Esri prototype
(`mistafunk/USD` branch `geospatial-prototype`); this variant drops the C++ library
and the baked-`resetXformStack` binding in favor of a neutral, relationship-based
binding resolved at runtime.

- **`CoordinateReferenceSystem`** (typed) — `crs:wkt` (+ optional `crs:epsg`,
  `crs:displayName`, `crs:epoch`, `crs:gridFiles`).
- **`BindingAPI`** (single-apply, `Xformable` only) — `crs:position` + `rel crs:binding`.

The reference runtime, Earth-2 converter, tests, and docs live in
`extras/usd/examples/usdGeospatial/`.

## Regenerating

`schema.usda` is the source. `plugInfo.json` + `resources/generatedSchema.usda` are
generated by `usdGenSchema`. The usd-core wheel doesn't ship the codegen templates
or the base meta-schema, so `regen-schema.sh` bootstraps them (no full USD build):

```bash
./regen-schema.sh            # regenerate in place
./regen-schema.sh --check    # CI: regenerate to temp and diff
```
